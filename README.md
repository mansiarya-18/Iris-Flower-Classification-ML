# Iris Flower Classification using Machine Learning

## Project Overview

This project uses Machine Learning algorithms to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

The Iris dataset is one of the most popular datasets for learning and practicing Machine Learning concepts.

## Dataset Information

The dataset contains 150 flower samples.

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Target Classes

- Setosa
- Versicolor
- Virginica

## Machine Learning Algorithms Used

1. K-Nearest Neighbors (KNN)
2. Decision Tree Classifier
3. Logistic Regression
4. Support Vector Machine (SVM)

## Steps Performed

1. Loaded Iris Dataset
2. Split Dataset into Training and Testing Sets
3. Trained Multiple Machine Learning Models
4. Evaluated Accuracy of Each Model
5. Predicted Flower Species for New Sample Data
